## About

Acadex is a student companion application designed to make academic life more organized and manageable. The Acadex website serves as its official landing page, providing information about the application, its features, installation instructions, and documentation.

The website introduces students to Acadex, a free and offline-capable Android application for managing class schedules, tasks, reminders, and campus information.

Built using HTML, CSS, and JavaScript, the website features a responsive layout, interactive documentation, animated elements, and a direct APK download.

**Ready to get started?** [Download Acadex for Android](https://github.com/kalabasaa/Acadex/releases/latest) and keep your academic life organized.

## Features

- **App Overview** – Introduces Acadex and its purpose as a student companion application.
- **Feature Showcase** – Highlights schedules, tasks, reminders, subjects, and campus tools.
- **Direct APK Download** – Provides access to the latest Acadex Android installation file.
- **Installation Guide** – Step-by-step instructions for installing Acadex on Android devices.
- **Interactive Documentation** – Expandable guides explaining how to use the application's features.
- **Campus Information** – Introduces the campus map and location directory.
- **What's New** – Highlights updates and improvements in the latest version.
- **Responsive Design** – Supports desktop and mobile screen sizes.
- **Animated Interface** – Includes visual transitions and interactive website elements.

## Getting Started

### Requirements

- A modern web browser.
- A local web server or static hosting platform.

### Installation

Open `index.html` in your browser, or run the website using a local development server.

The website does not require a backend server or database to display its static content.
